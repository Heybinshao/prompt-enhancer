# Prompt Enhancer for Hermes ![版本](https://img.shields.io/badge/版本-v1.0.9-blue)

【Hermes 桌面端插件】输入框「增强提示词」按钮——一句话草稿改写为结构化完整提示词。en / 简中 / 繁體。

![prompt-enhancer](assets/cover.jpg)

## 30 秒看懂

输入框右下角（模型选择器左侧）多了一个 ✨ 按钮：随手打一句模糊的话（「帮我写个周报」），点一下，草稿被替换为任务/范围/约束/输出形式一次到位的结构化提示词。不满意再点一下（图标变实心）恢复原文。

增强结果**只改写、不回答**：不替你执行任务，只把意图整理成 AI 更好执行的提示词。单次无状态调用，不进会话历史，不影响 prompt cache。语言跟随输入（英文输入 → 英文输出，混排保持混排）。

## 安装

**方式一：让 Hermes 帮你装（推荐）**

对 Hermes 说：

```
帮我安装这个桌面插件：https://github.com/Heybinshao/prompt-enhancer
```

**方式二：手动放置**

1. 下载本仓库的 `plugin.js`
2. 放到 `~/.hermes/desktop-plugins/prompt-enhancer/plugin.js`（文件夹名必须叫 `prompt-enhancer`）
3. 重启 Hermes 桌面端（⌘Q 后重新打开）

## 界面预览

按钮位于输入框控件行最左（模型选择器左侧）：

| 空闲态 | 增强后（可恢复） |
|--------|----------------|
| 空心火花 ✨ | 实心火花，点击恢复原文 |

## 使用

| 操作 | 效果 |
|------|------|
| 输入草稿后点 ✨ | 草稿被增强后的提示词替换 |
| 增强后再点 ✨（实心图标） | 恢复原文 |
| 增强等待期继续编辑 | 保护生效：不覆盖你的手改，弹提示 |
| 空输入框点 ✨ | 提示无可增强内容 |

- **模型路由**：继承当前会话的模型——主会话用主会话的，瓦片会话用瓦片自己的（多会话场景精确归属）
- **多行布局**：草稿换行后输入框进入堆叠布局（官方行为），按钮始终紧贴模型选择器左侧
- **发送后**：按钮自动回到空闲态（增强结果已随消息发出）

## 卸载

Settings → Plugins → Prompt Enhancer → 关闭开关；或直接删除 `~/.hermes/desktop-plugins/prompt-enhancer/` 文件夹后重启 Hermes。

## 边界与说明

- 文件/引用 chip 与文本混合的草稿：引用标记原样保留，只增强文本部分
- 草稿超过 8000 字符暂不支持
- 增强耗时取决于模型（通常数秒到 2 分钟），转圈即进行中；请求超时上限 3 分钟
- **语音输入纠错**：草稿里的同音/近音错别字、口误漏字会被自动识别修正（如「全休」→「全修」），不确定是否错误时保持原样
- **多会话状态隔离**：每个会话输入框的增强状态独立（转圈/恢复只作用于自己，取消不作废其他会话的请求）
- **增强中可取消**：点 ✨ 后按钮变为转圈动画，**转圈期间再点一次即可取消**（立即拿回输入框，迟到的增强结果自动丢弃）；取消/完成后自动恢复
- **限流重试可见**：触发 429 自动重试时按钮提示变为「限流重试中…」，不再是静默等待
- **服务端 429 限流自动重试**：网关上游渠道偶发限流（`增强失败：… 429`）时插件自动退避重试（3s / 5s 各一次）；若重试后仍失败，稍等几秒再点一次即可——限流是网关侧的瞬时状态，与插件和账号无关
- **固定增强用模型（Hermes 配置，非插件功能）**：默认继承当前会话模型（新会话走辅助模型）。想固定用某个模型，在 Hermes 的 `config.yaml` 加：

  ```yaml
  auxiliary:
    prompt_enhancement:
      provider: <你的 provider 名>
      model: <模型名>
      timeout: 120
  ```
- ⌘Z 撤销的是你的打字历史，撤销不了增强替换——恢复原文请用按钮
- 需要网关在线（增强走 `llm.oneshot` 网关通道）

## 工作原理

按钮注入官方 `composer.actions` 贡献区；读取草稿（复刻官方 `composerPlainText` 序列化语义）→ 带会话锚点调用 `llm.oneshot` 网关 RPC（无状态、继承会话模型、不污染 prompt cache）→ DOM 写回 + 官方 input 事件镜像进草稿 store。写回前做快照比对，草稿在等待期被手改则放弃应用——绝不覆盖用户的字。
